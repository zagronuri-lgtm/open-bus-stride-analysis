# מקורות נתונים — Open Bus Stride Analysis

מסמך זה מתעד את מקורות הנתונים החיצוניים שבהם הריפו משתמש (או מתעתד להשתמש) לצורך ניתוח תחבורה ציבורית בישראל. כל המקורות צריכים להיות **רשמיים, מתועדים, ובעלי רישיון ברור**.

## עקרון מנחה

אין לאחסן קובצי נתונים גולמיים גדולים (CSV/Parquet/XLSX) ב־Git. במקום זאת, מתעדים כאן את הקישור, הסכמה, והרישיון, ומספקים סקריפט loader תחת `src/` שמושך את הנתונים בזמן ריצה.

---

## 1. Open Bus Stride API (חסדנא)

- **URL:** https://open-bus-stride-api.hasadna.org.il/
- **OpenAPI Spec:** https://open-bus-stride-api.hasadna.org.il/openapi.json
- **בעלים:** [The Public Knowledge Workshop (Hasadna)](https://www.hasadna.org.il/)
- **רישיון:** Open Data
- **תוכן:** נתוני SIRI חיים + GTFS, נסיעות מתוכננות מול ביצוע, מיקומי אוטובוסים, עצירות.
- **שימוש בריפו:** `src/open_bus_stride_client.py`, `src/line_reliability_analyzer.py`, `src/endpoint_catalog.py`.

## 2. נסועה בקווי אוטובוס — משרד התחבורה

- **URL:** https://data.gov.il/dataset/ridership
- **CKAN package id:** `ridership`
- **בעלים:** משרד התחבורה והבטיחות בדרכים
- **פלטפורמה:** data.gov.il (CKAN)
- **רישיון:** [Israeli Government Open Data Use Terms](https://data.gov.il/terms)
- **תדירות עדכון:** רבעונית, בפרסום ידני
- **תוכן:** נתוני נסועה וקיבולת לפי קו, מפעיל, אשכול, כיוון, שנה ורבעון.

### שדות עיקריים שנצפו

| שדה מקורי | שדה מנורמל | תיאור |
|---|---|---|
| `RouteID` | `route_id` | מזהה קו במאגר |
| `RouteName` | `route_short_name` | מספר קו לציבור |
| `RouteDirection` | `route_direction` | כיוון |
| `AgencyName` | `agency_name` | שם מפעיל |
| `ClusterName` | `cluster_name` | שם אשכול |
| `WeeklyKM` | `weekly_km` | ק"מ שבועי |
| `WeeklyPassengers` | `weekly_passengers` | נוסעים שבועיים |
| `AverageSpeed` | `average_speed` | מהירות ממוצעת |
| `year` | `year` | שנה |
| `Q` | `quarter` | רבעון |

### חיבור לכלים הקיימים

- `src/ridership_fetch.py` מגלה את משאב ה־CSV העדכני דרך `package_show`, מושך את הרשומות דרך `datastore_search`, מנרמל עמודות, ושומר CSV תחת `data/raw/ridership_{year}Q{quarter}.csv`.
- מטא־דאטה קטן נשמר ב־`data/cache/ridership_meta.json` כדי לזהות האם resource_id או `metadata_modified` השתנו.
- בדיקות יחידה נמצאות ב־`tests/test_ridership_fetch.py` ומבוססות mock CKAN ללא קריאת רשת.

## 3. תפוסות באוטובוסים 2022 — סקר עליה (משרד התחבורה)

- **URL:** https://data.gov.il/he/datasets/ministry_of_transport/onboardbusta2022peima1
- **בעלים:** משרד התחבורה והבטיחות בדרכים
- **פלטפורמה:** data.gov.il (CKAN)
- **רישיון:** [Israeli Government Open Data Use Terms](https://data.gov.il/terms)
- **תדירות עדכון:** נתוני בסיס 2022 (שנתי/חד־פעמי)
- **תוכן:** סקר תפוסות (סקר עליה) על קווי אוטובוס בישראל — כמות נוסעים שעולים בכל תחנה, לפי קו, מפעיל, יום בשבוע, ושעה.

### שדות עיקריים (לאימות בטעינה ראשונה)

| שדה | תיאור |
|---|---|
| `operator` / מפעיל | אגד / דן / קווים / מטרופולין / סופרבוס / וכו' |
| `line_id` / מספר קו | מזהה קו ציבורי |
| `direction` / כיוון | הלוך/חזור |
| `stop_id` / תחנה | מזהה תחנה (GTFS) |
| `day_type` / סוג יום | חול / ו' / שבת / חג |
| `hour` / שעה | חלון שעה |
| `boardings` / עליות | מספר נוסעים שעלו |

> ⚠️ שמות העמודות המדויקים נטענים מ־CKAN בעת ריצה; ראו `src/onboard_occupancy_loader.py` עבור mapping.

### Use cases אנליטיים

1. **ביקוש מול היצע** — השוואה בין תפוסות בפועל (dataset זה) לבין נסיעות מתוכננות (Stride GTFS) לזיהוי קווים בתת/יתר־הצעה.
2. **מיקוד תוספות קו** — איתור קווים/שעות/תחנות שבהם הביקוש חורג מהיכולת.
3. **תיקוף אמינות** — הצלבה בין נתוני אמינות (Stride SIRI) לבין עומסי נוסעים — האם איחורים תכופים יותר בקווים עמוסים?
4. **תכנון רשת** — זיהוי תחנות שיא לפיתוח BRT / קווים מהירים.
5. **דשבורד אזורי** — חיתוך לפי אזור (למשל גוש דן / מטרופולין ירושלים) להצגת עומסים יחסיים.

### חיבור לכלים הקיימים

- ל־`line_reliability_analyzer.py` ניתן להוסיף `--occupancy-source onboard2022` שיצרף עמודת `mean_boardings` לפלט האמינות.
- ה־loader יוריד את הקובץ דרך CKAN API ויאחסן ב־cache מקומי (`.cache/onboard2022.parquet`) כדי להימנע מהורדות חוזרות.

- **URL:** https://gtfs.mot.gov.il/gtfsfiles/israel-public-transportation.zip
- **תוכן:** לוחות זמנים סטטיים של כל קווי האוטובוס/רכבת בישראל.
- **שימוש מתוכנן:** השלמת metadata על קווים שלא מופיעים ב־Stride.

## 4. מר קו — נתוני קווים וספירות נוסעים (מנהלת התחבורה הציבורית / עדליא)

- **URL:** https://markav.net/
- **בעלים:** מנהלת התחבורה הציבורית — עדליא, בסיוע יחידת המחקר ברשות הארצית לתחבורה הציבורית
- **רישיון/גישה:** צפייה פתוחה לכל מבקר (הערות תכנון דורשות הרשאה); גרסת בטא
- **תדירות עדכון:** רבעונית — נתוני "תקופת שגרה" אחרונה בלבד (ללא חגים, חופשות, מלחמות, בחירות ואירועים מיוחדים)
- **תוכן:** נתוני קווי אוטובוס למתכננים — כולל ספירות נוסעים/נסועה ברמת קו, מק"ט ותחנה. חיפוש לפי מספר קו, מק"ט או עיר.
- **דאטהסט משלים להורדה:** [נסועה בקווי אוטובוס — data.gov.il](https://data.gov.il/dataset/ridership)

### Use cases אנליטיים

1. **ביקוש מול היצע עדכני** — ספירות נוסעים רבעוניות ברמת קו, עדכניות יותר מסקר התפוסות 2022 (מקור 2 לעיל).
2. **תיעדוף רידוד/תגבור** — הצלבת אי-ביצוע ורידוד (Stride) עם עומסי נוסעים: ביטול נסיעה בקו עמוס חמור מביטול בקו ריק.
3. **בנצ'מרק שגרה** — תקופות המדידה של מר קו מנטרלות חגים ואירועים מיוחדים, בדומה למתודולוגיית הימים החריגים בריפו זה.

> ⚠️ הנתונים מייצגים תקופת שגרה אחרונה בלבד — אין להשוות ישירות לימי חג/חירום. הסבר תקופות המדידה: https://markav.net/page/6/
