# לוח החרגות 2026 — מקור אמת לניתוח אי-ביצוע / זמני נסיעה

מקור: Google Sheet `לוח_החרגות_2026` (גרסה 0.3, רשת מטרופולין). הומר ל-CSV נורמלי לשימוש דטרמיניסטי ע"י האוטומציות וסוכן הדוח. **שינויים יש לבצע בגיליון המקור ולהריץ מחדש את ההמרה**, או לערוך את ה-CSV ולסנכרן חזרה.

## שלוש קטגוריות הטיפול (עמודת `טיפול`)
- **drop** — החרגה מלאה: היום מעוות את ההתפלגות ואינו חוזר. נזרק. (חגים, ערבי חג, יום כיפור, אירוע חד-פעמי).
- **segment** — קיבוץ נפרד: דפוס אמיתי וחוזר אך שונה. מנותח בנפרד, **לא נזרק**. (חול המועד, חופש גדול, רמדאן, ימי תגבור/רידוד).
- **keep** — התעלמות: מיוחד בשם בלבד, ללא השפעה מהותית. נשאר. (צומות קלים, ל"ג בעומר).

> ⚠️ לעולם אל תבצע `drop` על תקופה ארוכה (חופש גדול, רמדאן) — תאבד דאטה רבה. השתמש ב-`segment`.

## הטיפול תלוי-אזור (העיקרון החשוב ביותר ברשת מטרופולין)
אותו חג אינו מטופל זהה בכל הסניפים. הלוח הקבוע/האסלאמי נותן ברירת מחדל ארצית; `05_regional_overrides.csv` דורס אותה לפי סניף/ייחודיות-קו.
- **אלעד (חרדית):** בחגים יהודיים — תגבור מתוכנן ולוח מיוחד → `segment` מקומי (מדידה מול הלוח המתוגבר), לא drop ולא keep.
- **סניפים מוסלמיים (המשולש/הנגב):** בחגי האסלאם — רידוד מתוכנן עד ~50% → `segment`.

## היררכיית ההכרעה לכל תאריך × סניף
1. קיים override ב-`05_regional_overrides.csv` התואם לתאריך ולסניף? אם כן — **הוא קובע**.
2. אחרת — החל את הטיפול מהלוח הקבוע (`01`) או האסלאמי (`02`), מוגבל ל-`חלון_שעות` ול-`היקף`.
3. **תעד תמיד:** כמה תצפיות הוחרגו/קובצו, מאיזה סוג, ובאיזה סניף.
